# utilidades-r

Scripts utilitarios en R para tareas locales: manipulación de archivos, procesamiento de documentos, y otras tareas repetitivas.

## Proyectos

- **[01 — Editor de PDFs](01-editor-pdf/README.md)**: combina, extrae y reordena páginas de PDFs sin subirlos a servicios web.

## Herramientas

- R: `qpdf`, entre otros.

## Contexto

Scripts que resuelven tareas puntuales de escritorio, sin depender de servicios web de terceros. Alternativas locales a herramientas que cobran licencia o que requieren subir archivos a internet.

Ver cada proyecto para detalles.
